# Support

**Stellen Sie dem GOAT-Team eine Frage, melden Sie ein Problem oder schlagen Sie eine Idee vor**, ohne GOAT zu verlassen. Aus jeder Anfrage wird ein Support-Ticket: Die Antworten verfolgen Sie in GOAT, und sie werden Ihnen auch per E-Mail geschickt.

## Das Support-Menü

Klicken Sie rechts in der oberen Leiste auf das Symbol <code>Support</code>. Auf dem Smartphone finden Sie dieselben Einträge im <code>Kontomenü</code>.

- <code>Support-Tickets</code>: **öffnet die Liste Ihrer Tickets**. Eine Zahl daneben zeigt, wie viele Tickets auf Ihre Antwort warten oder Antworten enthalten, die Sie noch nicht gelesen haben.
- <code>Problem melden</code>: **öffnet das Formular für ein neues Ticket**.
- <code>Dokumentation</code>: **öffnet diese Dokumentation** in einem neuen Tab.

Tickets, die Ihre Aufmerksamkeit brauchen, stehen oben im Menü, sodass Sie sie direkt öffnen können.

:::info
Auf Installationen ohne Support-Tickets öffnet <code>Problem melden</code> stattdessen eine E-Mail an das Support-Team, und es gibt keine Ticketliste.
:::

## Ein Ticket erstellen

<div class="step">
   <div class="step-number">1</div>
   <div class="content">Klicken Sie im Menü <code>Support</code> auf <code>Problem melden</code>. Sie können auch auf der Seite <code>Support</code> auf <code>Neues Ticket</code> klicken.</div>
</div>

<div class="step">
   <div class="step-number">2</div>
   <div class="content">Wählen Sie unter <code>Wobei brauchen Sie Hilfe?</code> <b>eine Kategorie</b>: <code>Fehler</code>, <code>Anleitung</code>, <code>Datenproblem</code>, <code>Funktionswunsch</code>, <code>Konto & Abrechnung</code> oder <code>Sonstiges</code>.</div>
</div>

<div class="step">
   <div class="step-number">3</div>
   <div class="content">Geben Sie einen <code>Betreff</code> und eine <code>Beschreibung</code> ein. Beschreiben Sie bei einem Fehler, was Sie getan haben, was Sie erwartet haben und was stattdessen passiert ist.</div>
</div>

<div class="step">
   <div class="step-number">4</div>
   <div class="content">Wählen Sie unter <code>Wie sehr blockiert Sie das?</code> <code>Nur eine Frage</code>, <code>Bremst mich aus</code> oder <code>Blockiert meine Arbeit</code>. Das hilft dem Team zu entscheiden, was es zuerst ansieht. Bei einem Funktionswunsch entfällt diese Frage.</div>
</div>

<div class="step">
   <div class="step-number">5</div>
   <div class="content">
   Ergänzen Sie bei Bedarf weiteren Kontext:
      <ul>
         <li><code>Zugehöriges Projekt</code>: das Projekt, um das es geht. Bei Tickets zu Konto & Abrechnung wird es nicht abgefragt.</li>
         <li><code>Anhänge</code>: Screenshots, exportierte Layer oder Logs. Bis zu 10 Dateien, je 10 MB und zusammen höchstens 50 MB.</li>
         <li><code>Kolleginnen und Kollegen einbeziehen</code>: Personen aus Ihrer Organisation, die mitlesen und antworten können und Updates auch per E-Mail erhalten.</li>
         <li><code>Technische Details anhängen</code>: die Seite, von der Sie kommen, Ihr Browser und Ihre Bildschirmgröße. Diese Option ist standardmäßig aktiviert.</li>
      </ul>
   </div>
</div>

<div class="step">
   <div class="step-number">6</div>
   <div class="content">Klicken Sie auf <code>Ticket senden</code>. Das Ticket öffnet sich, und <b>Sie erhalten eine Bestätigung per E-Mail</b>.</div>
</div>

:::tip
Ein Ticket ist sichtbar für Sie, die hinzugefügten Kolleginnen und Kollegen und die Admins Ihrer Organisation.
:::

## Ihre Tickets verfolgen

Die Seite <code>Support</code> listet Ihre Tickets unter <code>Offen</code> und <code>Geschlossen</code>. Suchen Sie nach Betreff oder Ticketnummer. Jedes Ticket zeigt seinen Status:

| Status | Bedeutung |
|---|---|
| <code>Eingereicht</code> | Das Ticket ist angekommen und wartet auf das Team. |
| <code>In Bearbeitung</code> | Jemand aus dem GOAT-Team arbeitet daran. |
| <code>Wartet auf Ihre Antwort</code> | Das Team hat Ihnen eine Frage gestellt. |
| <code>Gelöst</code> | Das Team hat es gelöst. |
| <code>Geschlossen</code> | Das Ticket ist geschlossen. |

Öffnen Sie ein Ticket, um **den Verlauf zu lesen und zu antworten**. Sie können einer Antwort Dateien anhängen und auch per E-Mail antworten. Rechts sehen Sie, wer das Ticket bearbeitet, die <code>Beteiligten</code> und die Details. Wenn Sie die Beteiligten verwalten dürfen, können Sie dort Kolleginnen und Kollegen hinzufügen, und sich selbst können Sie jederzeit entfernen.

Ist Ihr Problem gelöst, klicken Sie auf <code>Als gelöst markieren</code>. Tritt es wieder auf, klicken Sie auf <code>Wieder öffnen</code> oder antworten Sie einfach. Bei einem gelösten Ticket können Sie bewerten, wie zufrieden Sie mit dem Team waren.

:::info
**Organisations-Admins sehen alle Tickets ihrer Organisation.** Auf der Seite <code>Support</code> können sie zwischen <code>Meine Tickets</code> und <code>Organisation</code> wechseln. Mitglieder sehen nur Tickets, die sie eröffnet haben oder zu denen sie hinzugefügt wurden.
:::
