# Karte teilen

Im letzten Schritt unseres Tutorials zeigen wir Ihnen, wie Sie Ihre fertige Analyse mit anderen teilen können.

1. **Klicken Sie auf `Teilen`** in der oberen rechten Ecke der Kartenansicht
2. **Klicken Sie auf die Registerkarte `Öffentlich`**
3. **Klicken Sie auf `Veröffentlichen`** 

🎉 **Fertig!** Ihre Karte ist jetzt öffentlich verfügbar.

4. Jetzt können Sie:
-  🔗 **URL kopieren**: Teilen Sie den direkten Link, damit andere die Karte in ihrem Browser öffnen können.
- 🖥️ **iframe-Code kopieren**: Betten Sie die Karte in Websites oder Tools ein, die HTML und iframes unterstützen.
